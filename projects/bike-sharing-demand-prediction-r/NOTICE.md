# Dataset attribution

This repository includes a prepared derivative of the UCI Machine Learning Repository **Bike Sharing** dataset.

**Source**

Fanaee-T, H. (2013). *Bike Sharing* [Dataset]. UCI Machine Learning Repository.  
DOI: 10.24432/C5W894

**Dataset license**

Creative Commons Attribution 4.0 International (CC BY 4.0).

The prepared CSV used in this repository removes fields that were not used by the predictive workflow. Attribution to the original dataset is retained.

## Code licensing

No separate open-source license is granted for the repository code at this stage. The original work was collaborative, so an explicit code license should only be added after confirming the rights of all relevant contributors.
